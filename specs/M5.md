# M5 — Semantic drift + coinage (implementation spec)

Depends on M3's history driver. Deliverables: a curated drift graph, drift/taboo event
mechanics integrated into the per-century simulation loop, coinage (refill) of gapped
concepts by compounding — with the crucial property that coined compounds are built from the
branch's *current* forms and then keep eroding phonologically — and dictionary/trace output
that narrates semantic history.

## Why this matters

Sound change alone diverges *forms*; drift diverges *meanings*. After M5, two daughters can
both descend a word from the same root where one still means "sun" and the other means "day" —
and the second language has coined "sky-fire" to fill the gap. That's the texture of real
families.

## Event model (`src/drift.ts`)

```ts
type DriftEvent =
  | { kind: 'shift';  century: number; from: string; to: string; note: string }
    // the word for `from` comes to mean `to` (old `to` word, if any, is lost);
    // `from` is refilled by coinage (below)
  | { kind: 'extend'; century: number; from: string; to: string; note: string }
    // colexification: the word for `from` now ALSO covers `to`; `to`'s own word is lost;
    // no gap, no coinage — the dictionary lists both senses
  | { kind: 'taboo';  century: number; concept: string; note: string };
    // the word is replaced outright by a euphemistic compound; old word is lost
```

Events go into the same per-branch event log as sound changes (M3's `ChangeEvent` becomes a
union; sound-change replay must be unaffected). All notes are human-readable and surface in
dictionaries and traces, e.g. `"originally 'sun'; came to mean 'day' c. year 900"`.

## Taboo replacement

`TABOO_CONCEPTS: { concept: string; w: number; euphemisms: [string, string][] }[]` — dangerous
or numinous things get renamed by description (historically attested pattern for each):

- bear 3 → [honey, eat] ("honey-eater", Slavic *medvědь*), [old, man] ("old one")
- wolf 3 → [night, dog], [bad, dog]
- snake 2 → [earth, worm], [long, worm]
- death 2 → [long, sleep], [go, night]
- god 1 → [sky, father], [light, king]

The euphemism is built as a compound (below); the event note names the pattern:
`"taboo replacement: 'bear' renamed as honey-eater, c. year 1200"`.

## Coinage (`src/drift.ts`, reusing lexicon compound machinery)

`REFILL_TEMPLATES: Record<string, [string, string][]>` — when `shift` gaps a concept, coin a
compound from the first template whose parts are currently expressible; if none, fall back to
generic `[<domain-anchor>, <concept's old word> + diminutive affix]`, and as a last resort
re-derive with the adjective-izer. A few curated ones:

- sun → [day, eye] ("day's eye"), [sky, fire]
- day → [sun, go]
- moon → [night, sun], [night, light]
- night → [dark, sky]
- spirit → [breath, man]
- year → [summer, winter]
- hand → [finger, house]  // "finger-holder"; deliberately quirky is fine
- king → [war, father], [law, chief]
- sea → [big, water]  // may re-coin what M1 already lexicalized; that's realistic renewal

**Erosion property (the whole point):** a coined word is assembled from the branch's
*current, already-evolved* forms at the coinage century, then participates in all later sound
changes like any other word. Store coined Words in the branch's working lexicon and record
`{ coinedAt, parts }` for the dictionary. Do NOT rebuild compounds from proto roots at query
time — `trace` for a coined word starts at the coinage century with the note
`"coined c. year 1300 from <part> + <part>"` and shows only subsequent sound changes.

## Rates & scheduling (config, defaults)

- `driftChance` 0.10 /branch/century → at most ONE drift event (shift or extend) per branch
  per century; edge sampled by weight among edges whose `from` is currently expressible.
- `tabooChance` 0.02 /branch/century, sampled independently; skip if that concept already
  tabooed on this path.
- Never drift a concept that was drift-affected on this path within the last 3 centuries.
- All sampling from the branch's own named stream — but use a NEW stream family
  (`drift:<branchId>`) so M3's sound-change histories for a given seed are byte-identical
  before/after this milestone (M3 goldens must not change; this is acceptance-tested).

## Query/output changes

- `dict`: each entry gains `senses` (current meaning(s)), `notes` (semantic history lines),
  and `coined`/`taboo` annotations.
- `trace`: prepend/append semantic notes at the centuries they occurred.
- `cognates <concept>`: a leaf whose word for the concept is not cognate (coined/tabooed)
  shows the form marked with `†` and the JSON carries `cognate: false`. This makes the
  cognate table honestly reflect lexical replacement — some cells SHOULD break the pattern.

## Acceptance criteria

1. M3's golden `generate` outputs for seeds 1/42/2026 are unchanged when drift is DISABLED
   (`--no-drift` config flag), and — because of the separate stream family — the sound-change
   event sequences are identical even when drift is enabled.
2. New goldens (drift enabled, seeds 1/42/2026) show at least one shift, one extend, and one
   taboo event across the three seeds combined; eyeball and paste them in the report.
3. Property (≥25 seeds): every concept is expressible in every leaf at year-end (senses or
   dedicated word); no branch exceeds 1 drift event per century; no concept drifts twice
   within 3 centuries on one path.
4. Erosion test: construct a scripted history where a coinage at century N is followed by
   sound changes; assert the coined word's final form differs from a freshly-built compound
   of the parts' final forms (i.e. the coinage genuinely eroded from its coinage-time shape).
5. Graph integrity: module-load validation that every id in DRIFT_EDGES, TABOO_CONCEPTS, and
   REFILL_TEMPLATES exists in CONCEPTS (unit test + the load-time throw).
6. Determinism + round-trip: drift events serialize in the JSON dump (bump formatVersion
   to 2 with a compatibility note) and survive toJSON/fromJSON.
