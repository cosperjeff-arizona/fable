# M1 — Phonology + Lexicon (implementation spec)

Goal: replace the prototype's symbol-string phonology with a typed feature system, and grow
the lexicon to ~200 concepts with basic morphology. This milestone produces `@etymon/core`'s
foundation modules plus the project scaffold. No sound changes yet (that's M2) — but every
type here is designed so M2 rules can target features.

## Scaffold

- TypeScript, `"type": "module"`, strict tsconfig (`strict`, `noUncheckedIndexedAccess`).
- Zero runtime dependencies. Dev deps: `typescript`, `vitest` only.
- Layout: `src/prng.ts`, `src/phonology.ts`, `src/lexicon.ts`, `src/concepts.ts`,
  `src/romanize.ts`, tests in `test/*.test.ts`. `npm test` runs vitest; `npm run build` runs tsc.
- Keep `prototype/` untouched — it stays as the historical PoC.

## `src/prng.ts`

- `mulberry32`-style seeded PRNG. Export a `Stream` class: `next()`, `pick(arr)`,
  `weightedPick(pairs)`, `chance(p)`, `shuffle(arr)` (non-mutating), `int(lo, hi)`.
- **Named streams**: `makeStreams(seed)` returns independent streams derived from the master
  seed by hashing stream names (`'phonology'`, `'lexicon'`, `'history'`, `'branch:<id>'`).
  Purpose: adding a feature that consumes randomness in one subsystem must not reshuffle the
  output of others. Test this property explicitly.

## `src/phonology.ts` — segment model

```ts
export type Consonant = {
  type: 'C';
  place: 'labial' | 'dental' | 'alveolar' | 'postalveolar' | 'palatal' | 'velar' | 'glottal';
  manner: 'stop' | 'affricate' | 'fricative' | 'nasal' | 'rhotic' | 'lateral' | 'glide';
  voiced: boolean;
};
export type Vowel = {
  type: 'V';
  height: 'high' | 'mid' | 'low';
  backness: 'front' | 'central' | 'back';
  rounded: boolean;
  long: boolean;   // proto-languages may or may not contrast length
  nasal: boolean;  // always false at generation time; sound changes create it later
};
export type Segment = Consonant | Vowel;
export type Word = { segments: Segment[]; stress: number }; // index of stressed vowel segment
```

- Segments are compared/keyed by a canonical string form (`segKey(seg)`); words by
  `wordKey(word)`. Diphthongs are vowel–vowel sequences, no special type.
- Provide a small IPA-ish table mapping feature bundles ↔ canonical symbols for debugging
  (`p`, `t`, `k`, `b`, …, `ʃ` as `sh`, `tʃ` as `ch`, `j`, `w`, `y` for /y/…). Not every
  combination needs a symbol — unknown bundles render as bracketed feature abbreviations.

## Inventory generation

`generateInventory(stream): Inventory` where
`Inventory = { consonants: Consonant[]; vowels: Vowel[]; phonotactics: Phonotactics }`.

Sample structured **series**, not individual phonemes, respecting implicational universals:

- Voiceless stops /p t k/: always present.
- Voiced stops /b d g/: 60 %. (Never voiced without voiceless.)
- Fricatives: /s/ always; add /f/ 70 %, /h/ 60 %, /ʃ/ 35 %, voiced counterparts /z v/ only if
  voiced stops exist (then 40 %).
- Affricates /tʃ/ (and /dʒ/ if voiced series): 25 %.
- Nasals /m n/: always. Liquids: at least one of /r l/ (both 70 %). Glides /w j/: each 65 %.
- Vowel systems (weighted): 5-way /i e a o u/ 45 %; 3-way /i a u/ 20 %; 6-way (5 + /ə/ central
  mid) 15 %; 7-way (5 + /ɛ ɔ/ — represent as low-mid via `height:'mid'` + a `lowMid` boolean?
  **No** — keep the model simple: 7-way is 5-way + front rounded /y ø/) 10 %; 4-way /i e a o/ 10 %.
- Length contrast on vowels: 35 % of proto-languages. If present, roots may contain long vowels.
- Target consonant inventory size 12–22; if sampling lands outside, resample.

`Phonotactics`:

```ts
type Phonotactics = {
  maxOnset: 1 | 2;                 // 2 with 40% probability; cluster = {stop,fricative} + {liquid,glide}
  codas: Consonant[];              // subset: nasals + /s/ always allowed if present; liquids 60%; stops 40%
  allowFinalVowel: boolean;        // 90% true
};
```

`isLegalWord(word, phonotactics): boolean` — used by tests and later by loanword adaptation.

## `src/concepts.ts` — 200 concepts

A curated flat list of concept ids with semantic domains:

```ts
export type Concept = { id: string; domain: Domain; core: boolean };
```

- Include the prototype's 32 as `core: true`, plus the rest of the Swadesh-100 that make
  sense for nouns/verbs/adjectives of a pre-industrial world.
- Domains and rough counts: `nature` 40, `body` 25, `kinship` 15, `animals` 20, `plants/food`
  20, `artifacts/tools` 20, `society/power` 15, `actions` (verbs: eat, drink, sleep, die, see,
  hear, give, take, go, come, make, cut, burn, speak, know…) 25, `qualities` (adjectives: big,
  small, old, new, good, bad, hot, cold, long, heavy…) 15, `abstract` (spirit, dream, name,
  luck, death, time) 5.
- Pick concepts that future drift edges can connect (moon/month, hand/five, breath/spirit,
  heart/courage, sun/day, fire/hearth, water-big/sea). Flag the final list for owner review
  in the PR/commit message.

## `src/lexicon.ts` — roots, morphology, compounds

`generateLexicon(inventory, concepts, stream): Lexicon`

- **Roots**: syllable count 1 (20 %), 2 (65 %), 3 (15 %). Build syllables from phonotactics
  (onset optional 15 % word-initially only, nucleus, coda per coda rules; monosyllables always
  get an onset and 70 % a coda). Reject homophones (`wordKey` collision) and near-collisions
  with existing roots (identical except length on one vowel). Stress: initial syllable.
- Not every concept gets a root: ~170 do. The rest are **compounds/derivations** created at
  generation time (e.g. `sea = water + big`, `ash = fire + dust`) using a small curated table
  in `concepts.ts` (`derivedFrom?: [id, id] | { root: id; affix: AffixRole }`).
- **Morphology**: generate 3–5 derivational affixes (agent `-er`, diminutive, place-of,
  negation, adjective-izer) and 2–4 inflectional (plural, past, genitive, and 50 % an
  accusative case). Each affix = a short segment sequence (1 syllable max) + `prefix|suffix`
  slot (85 % suffixing language). Store as paradigms:

```ts
type Affix = { role: string; kind: 'derivational' | 'inflectional'; slot: 'prefix' | 'suffix'; form: Segment[] };
type Lexeme = { concept: string; word: Word; origin: 'root' | 'compound' | 'derived'; parts?: string[] };
type Lexicon = { lexemes: Map<string, Lexeme>; affixes: Affix[] };
```

Inflected forms are *not* stored — they're produced on demand by `inflect(lexeme, affix)`.
(M2's paradigm-collapse detection will apply sound changes to inflected forms on demand.)

## `src/romanize.ts`

`romanize(word): string` — single default transcription for now (per-language orthographies
are M7). Long vowels double the letter; /j/ → `y`; /ʃ tʃ dʒ/ → `sh ch j`; /y ø/ → `ü ö`;
/ə/ → `ë`. Must round-trip: `parse(romanize(w))` equals `w` for all generable words (test it).

## Acceptance criteria

1. `npm test` green; `npm run build` clean.
2. **Determinism**: two runs with the same seed produce deep-equal inventories and lexicons;
   golden snapshot test for seeds 1, 42, 2026.
3. **Stream independence**: consuming extra randomness from the `lexicon` stream does not
   change `phonology` output.
4. **Property tests** (run over ≥20 seeds): every root satisfies `isLegalWord`; zero homophone
   collisions; inventory sizes within bounds; every concept resolves to a lexeme (root or
   derived); romanization round-trips.
5. A tiny demo script (`npm run demo -- --seed 42`) printing the inventory and 30 sample
   entries, to eyeball quality.
