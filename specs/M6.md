# M6 — Contact & borrowing (implementation spec)

Depends on M5 (drift events establish the event-union machinery and formatVersion 2).
Deliverables: a deterministic geography, borrowing events with loanword adaptation, doublet
tracking, and the `doublets` CLI query. This is the milestone that produces shirt/skirt pairs.

## Geography (`src/contact.ts`)

Deterministic, zero randomness: the root branch owns the interval [0, 1]; on a split, the
children get the left and right halves of the parent's interval (child `.0` left, `.1`
right). Two living branches are **adjacent** iff their intervals share an endpoint. This
models populations spreading apart as they diverge, gives every branch 1-2 neighbors, and
costs nothing. Store each branch's interval on the Branch record (serialized).

## Borrowing events

Per century, for each adjacent pair of living branches (pairs enumerated in deterministic
order: by interval position), with chance `borrowChance` (default 0.04): one word is borrowed.

- **Randomness discipline**: all draws for a pair come from a dedicated stream
  `contact:<idA>|<idB>` (ids sorted lexicographically; created via makeStreams' named-stream
  hashing). Branch sound-change streams are never touched by contact.
- **Direction**: 50/50 from the pair stream.
- **Concept choice**: weighted by domain — society/power and artifacts/tools x4 (wanderwort
  material: salt, iron, king, law, wheel, bread…), plants/food and animals x2, everything
  else x1, body and kinship x0.5. Sampled from concepts currently expressible in the source.
- **Adaptation**: each segment of the source's *current* form maps to the nearest segment in
  the borrower's *current* inventory (segments in use across its working lexicon). Feature
  distance: consonants — place 2, manner 3, voiced 1 (pick minimum total; ties broken by
  catalog order); vowels — height 2, backness 2, rounded 1, nasal 3, long 1. A perfect match
  keeps the segment. The adapted word then evolves under all subsequent borrower changes,
  like any native word.
- **Doublets**: if the borrower already expresses the concept, the loan REPLACES the concept
  binding and the native word is retained as a doublet: it stays in the working lexicon
  (keeps evolving) with a sense note ("archaic/register variant"), unless a drift edge from
  the concept exists, in which case the native word shifts along it (reusing M5 shift
  machinery, marked `note: "displaced by loan"`).

Event record (joins the M5 event union; bump formatVersion to 3):

```ts
{ kind: 'borrow'; century: number; concept: string;
  fromBranchId: string; sourceRomanized: string; adaptedRomanized: string; note: string }
```

## Query & output

- `doublets <language>` CLI command + `doublets(sim, branchId)` query: concepts where a leaf
  holds both an inherited and a borrowed line (or a displaced native word), showing both
  forms with their full traces — the etymological money shot. Render style:
  `salt: "solt" (inherited < *salta) vs "zalt" (borrowed from Ges, year 1400)`.
- `trace` on a borrowed word starts at the borrowing century:
  `< borrowed from Ges "zalta", year 1400 (adapted: z > s unavailable... )` then sound steps.
- `dict` marks loans with their source language and century.
- Cognate tables mark borrowed cells `‡` (distinct from M5's coined `†`).

## Interaction with sound-change sampling (honest note)

Loanwords join the working lexicon, so they participate in dry-run rejection counts and
`applicable()` checks; a borrowing CAN therefore legitimately alter which sound changes a
branch later samples (loans change the phonological ecology — that's realistic, not a bug).
Acceptance therefore requires byte-identical M5 behavior only when contact is DISABLED
(`--no-contact`), plus full determinism when enabled.

## Acceptance criteria

1. With `--no-contact`, output is byte-identical to pre-M6 for seeds 1/42/2026 (goldens).
2. Determinism when enabled: same seed twice → deep-equal simulations (including doublets).
3. Adaptation property test (≥15 seeds): every borrowed form's segments all exist in the
   borrower's inventory-in-use at the borrowing century.
4. Doublet integrity: every doublet's two lines both replay correctly via trace (inherited
   line from proto; borrowed line from the borrowing century).
5. Geography: unit tests for interval halving and adjacency; property — every living branch
   has ≥1 neighbor whenever ≥2 branches live.
6. At default rates over seeds 1-25, at least a third of simulations contain ≥1 doublet
   (tune borrowChance if not, and say so in the report).
7. Round-trip: borrow events survive toJSON/fromJSON; formatVersion 3 with fromJSON
   accepting 1/2 (missing sections treated as empty).
