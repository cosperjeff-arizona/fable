# M2 — Sound-change engine (implementation spec)

The heart of Etymon. Depends on M1's segment/word model. Deliverables: a rule representation
over features, deterministic rule application, a catalog of ~38 changes with plausibility
conditioning, and the candidate-rejection mechanism ("dry-run") that keeps simulated histories
from degenerating.

## Rule representation (`src/changes/rules.ts`)

```ts
type SegPattern = Partial<Omit<Consonant, 'type'>> & Partial<Omit<Vowel, 'type'>> & { type?: 'C' | 'V' };
// matches a segment iff every specified feature matches

type ContextAtom =
  | { kind: 'boundary' }             // word edge (#)
  | { kind: 'seg'; pattern: SegPattern }
  | { kind: 'stressedV' } | { kind: 'unstressedV' };

type Action =
  | { kind: 'set'; delta: Partial<Consonant> | Partial<Vowel> }  // feature rewrite (may flip C-ness? no — see below)
  | { kind: 'delete' }
  | { kind: 'replace'; segments: Segment[] }                      // for diphthongization, affrication
  | { kind: 'insertBefore'; segment: Segment } | { kind: 'insertAfter'; segment: Segment };

type SubRule = { match: SegPattern; env: { before?: ContextAtom[]; after?: ContextAtom[] }; action: Action };

type SoundChange = {
  id: string;
  family: 'lenition' | 'fortition' | 'deletion' | 'assimilation' | 'vowelshift'
        | 'palatalization' | 'epenthesis' | 'metathesis' | 'other';
  weight: number;                       // base sampling weight
  describe(): string;                   // human-readable, used in etymologies
  subRules: SubRule[];                  // applied in order; each simultaneous (see semantics)
  applicable(state: LangState): boolean;
};
```

- `set` never changes `type`; C↔V transformations (vocalization) use `replace`.
- Environments look at *segments*, plus stress. No syllable structure in v1 environments —
  provide `syllabify(word)` as a helper only for stress/syncope logic.
- `LangState` = current inventory (computed from lexicon: set of `segKey`s in use), recent
  change ids (last 4), and access to the current lexicon for dry-runs.

### Application semantics (`src/changes/apply.ts`)

`applyChange(word, change): Word`:

1. For each subRule in order: scan segments left-to-right, collect **all** match positions
   against the *pre-subRule* word (simultaneous application — no self-feeding within a
   subRule), then apply actions right-to-left so indices stay valid.
2. Stress index is remapped through insertions/deletions; if the stressed vowel is deleted,
   stress moves to the nearest surviving vowel to the left (else right).
3. **Word guard**: if the result has < 2 segments or no vowel, return the input unchanged
   (models analogical restoration). Guard per word, not per subRule.
4. Pure function; returns the same reference if nothing changed (cheap trace detection).

`evolve(word, changes): { form: Word; steps: { form: Word; changeId: string }[] }` — replays
history, recording only steps that altered the form. This must reproduce exactly what the
simulation did (same code path).

## The catalog (`src/changes/catalog.ts`)

Each entry below becomes a factory `(stream) => SoundChange` (some sample a variant). Notation:
informal rule / environment / preconditions. Every entry needs a unit test with hand-written
before/after words.

**Lenition & fortition**
1. `voicing` — p t k > b d g / V_V.
2. `spirantization` — b d g > v z ɣ→h / V_V. (ɣ is not in the segment table: use `h`.)
3. `final-devoicing` — b d g v z > p t k f s / _#. Precondition: voiced obstruents exist.
4. `w-fortition` — w > v everywhere.
5. `glide-fortition` — j > dʒ / #_. Precondition: affricates or voiced stops exist.
6. `degemination` — CC (identical) > C. Precondition: geminates present in lexicon.

**Deletion**
7. `apocope` — final unstressed V > ∅ / C_#. Weight high; classic.
8. `syncope` — medial unstressed V > ∅ when flanked by single Cs (no CCC creation).
9. `final-stop-loss` — stops > ∅ / _# (words of ≥3 segments).
10. `h-loss` — h > ∅ everywhere.
11. `initial-cluster-reduction` — #CC > #C (keep second).
12. `final-n-loss-with-nasalization` — V n > Ṽ / _# (vowel gains `nasal`, n deleted).
    This is how nasal vowels are *born* — precondition: none.
13. `unstressed-vowel-reduction` — unstressed non-low V > ə. Precondition: ə available or
    vowel system ≥5. (Creates ə if absent — inventory grows.)

**Assimilation & palatalization**
14. `nasal-place-assim` — n > m / _labial stop; m > n / _alveolar stop.
15. `cluster-voicing-assim` — obstruent voicing agrees with a following obstruent.
16. `palatalization-velar` — k g > tʃ dʒ / _{i, e, j, y}.
17. `palatalization-alveolar` — t d s > tʃ dʒ ʃ / _{i, j}. Rarer variant (lower weight).
18. `umlaut` — a o u > e ø y when next syllable's vowel is i/j. Precondition: front vowels
    exist. Introduces /ø y/ into inventories that lacked them (Germanic-style).
19. `total-assim-nt` — nt > tt (then feeds degemination later). Lower weight.

**Vowel shifts** (each dry-run checked, see below)
20. `chain-raising` — a > ɔ→o, o > u (long vowels first if length exists; else all).
21. `fronting-u` — u > y. Precondition: /y/ absent (else merger — allowed but weight halved).
22. `raising-e` — e > i.
23. `fronting-a` — a > e / in umlaut-free systems only (avoid double-application weirdness).
24. `diphthongization` — long mid vowels eː oː > ie uo (replace with two short vowels).
    Precondition: length contrast.
25. `monophthongization` — ai au > eː oː (or e o if no length). Precondition: diphthongs
    attested in lexicon.
26. `length-loss` — long V > short V everywhere (kills the length contrast; big event,
    low weight). Precondition: length contrast.
27. `nasal-vowel-merger` — Ṽ distinctions collapse: nasal vowels lose height contrast
    (mid+high > mid). Precondition: ≥2 nasal vowel qualities in lexicon.

**Epenthesis**
28. `prothesis` — ∅ > e / #_sC (Spanish-style). Precondition: #sC words exist.
29. `anaptyxis` — ∅ > ə (or a if no ə) inside CC codas / clusters of falling sonority.
30. `paragoge` — ∅ > e / obstruent_# (low weight; feeds later apocope amusingly).

**Other**
31. `rhotacism` — s z > r / V_V. Precondition: /r/ exists.
32. `debuccalization` — s > h / #_ (Greek-style). 
33. `liquid-metathesis` — CVrC > CrVC style: r and adjacent V swap in closed syllables.
    Low weight; delightful in etymologies.
34. `l-vocalization` — l > w / _C and _#. Precondition: /w/ exists.
35. `grimm-bundle` — series shift as one event: [p t k > f θ→s x→h] then [b d g > p t k].
    Very low weight (once per family at most — `applicable` checks it never ran anywhere
    on the ancestor path). The showpiece.
36. `intervocalic-glide-loss` — j w > ∅ / V_V (with vowel hiatus left as-is).
37. `hiatus-resolution` — V.V (identical) > single long V (or single short if no length).
    Precondition: hiatus exists in lexicon (often fed by 36 or 10 — test this feeding chain!).
38. `stress-shift-initial` — stress moves to first syllable (no segmental effect, but
    changes future apocope/syncope targets). Low weight.

## Sampling & plausibility (`src/changes/sample.ts`)

`sampleChange(state, stream): SoundChange | null`:

1. Filter catalog by `applicable(state)`; drop ids in `state.recentChangeIds`.
2. Weighted pick by `weight` (family-level balancing: deletion-family weight is multiplied by
   0.5 if the last 2 changes were deletions — histories shouldn't be pure erosion).
3. **Dry-run rejection**: apply the candidate to every lexeme (citation forms only). Reject if
   (a) homophone-pair count rises by more than 6 % of lexicon size, or (b) any of: vowel
   qualities in use would drop below 3, consonants in use below 8. On rejection, resample
   (max 8 attempts, then return null = quiet century).

This mechanism is the difference between "random rules" and "plausible history" — a change
that would merge a third of the vocabulary gets vetoed, exactly like real languages route
around catastrophic mergers.

## Paradigm-collapse detection (`src/changes/paradigms.ts`)

After each applied change, for each inflectional affix: inflect 20 sample lexemes, apply the
full change history, and check whether the inflected form still differs from the citation
form. If <30 % differ, mark the affix `collapsed` at that century and record a note (used
later in language profiles: "the accusative case was lost to apocope, c. year 1200"). No
syntax simulation — just detection + reporting.

## Acceptance criteria

1. Unit test per catalog entry: hand-constructed input word(s) → expected output (romanized
   comparison is fine). Include at least one negative case (environment not met) each.
2. Feeding-chain test: h-loss → hiatus-resolution produces a long vowel end-to-end.
3. Simultaneity test: `voicing` on `atata` yields `adada` (not fed), i.e. both apply from the
   same pre-state; deletion index-remapping test with multiple deletions in one word.
4. Stress remapping tests (deleted stressed vowel; insertions before stress).
5. Dry-run rejection test: construct a small lexicon where `raising-e` merges 20 % of pairs
   and assert it's vetoed and resampled.
6. Determinism + golden snapshots: `evolve` over a scripted 10-change history for 3 seeds.
7. `grimm-bundle` uniqueness: applicable-check test that it can't fire twice on one path.
