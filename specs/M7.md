# M7 — Orthographies + polish (implementation spec)

Final milestone: per-language orthographies, coinage quality tuning, output nits, and docs.
Display-layer only — no simulation-content changes except coinage length tuning.

## Per-language orthographies (`src/orthography.ts`)

Each leaf gets deterministic orthographic conventions from a new stream family
`orthography:<branchId>`, sampled at query/render time (NOT during simulation — zero effect
on any event stream or golden that doesn't display leaf forms). An `Orthography` is a set of
convention choices; sample each independently:

- /k/: `k` (60%) or `c` (40%, but `k` before front vowels i/e/y/ö to keep it readable)
- /tʃ/: `ch` / `c` / `tš` (50/25/25); /dʒ/: `j` / `dj` (70/30); /ʃ/: `sh` / `š` / `x` (50/30/20)
- /j/: `y` (60%) or `j` (40%, only if /dʒ/ isn't `j`)
- /y/, /ø/: `ü ö` (50%) or `y ö` (25%, only if glide isn't `y`) or `ue oe` (25%)
- /ə/: `ë` (60%) or `e` (25%, merging with /e/ in spelling — realistic!) or `ă` (15%)
- long vowels: doubled letter (60%) or macron ā ē ī ō ū (40%)
- nasal vowels: tilde ã ẽ ĩ õ ũ (60%) or ogonek-style `ą ę į ǫ ų` (20%) or `n` after the vowel
  (20%, only when no true /Vn/ ambiguity exists in that word — else fall back to tilde)

The bare `~` notation must no longer appear in any leaf display. Proto forms (`*...`) keep
the existing neutral phonemic romanization everywhere. `romanize.ts` stays the phonemic
backbone (JSON `romanized` fields stay phonemic); add `spell(word, orthography)` for display.
`dict`/`trace`/`cognates`/`doublets` CLI output and the explorer show leaf spellings (the
explorer gets per-leaf orthography data in the dump — additive field, formatVersion stays 3;
show phonemic form in parentheses in the etymology timeline where it differs from spelling).

## Coinage quality tuning (`src/drift.ts`)

- If a coined compound would exceed 4 syllables, clip the FIRST part to its initial syllable
  (attested compound-clipping). Property test: no coined word exceeds 5 syllables (≥25 seeds,
  drift+taboo enabled).
- Generic fallback template must not produce `X + X-diminutive` self-compounds; use the
  domain anchor + a *quality* concept's word instead when the gap concept is its own only
  material. These change drift-enabled outputs: update affected goldens deliberately and list
  them in the commit message.

## Output nits

- Coined/borrowed trace headers: show the origin-time form, e.g.
  `"dischëjis'hisnëstu" (hearth) — coined as "deskëjes'hesnëstu" from stone + hearth (little), c. year 1200`.
  (The origin-time form is already stored on the reassignment record.)
- Drift/taboo note lines currently duplicate the year ("year 1200 … c. year 1200" in branch
  history); strip the trailing "c. year N" from notes when rendered next to a year column.
- The apostrophe morpheme-separator inside coined compounds may remain in phonemic
  romanization but must not appear in leaf spellings (drop it in `spell`).
